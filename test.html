🎮 TurboWarp Developer Console Extension - Test Page

How to Test This Extension

  1. Open TurboWarp at https://turbowarp.org/
  2. Click on "Extensions" in the bottom left corner
  3. Select "Load Extension from URL" or "Load Extension from File"
  4. If using URL: Enter the hosted URL of developer-console.js
  5. If using File: Select the developer-console.js file from this project
  6. The extension will load and appear in your blocks palette

🎯 Features to Test

  • Console toggle with ~ key
  • Console close with Escape key
  • Text input field with cursor
  • Command registration via blocks
  • Command execution with arguments
  • Autocomplete dropdown with strict prefix matching
  • Autocomplete navigation with arrow keys
  • Tab/Enter to accept autocomplete suggestions
  • Command history navigation with up/down arrows
  • Output display with normal and error messages
  • Console styling customization blocks
  • Custom CSS support

⌨️ Keyboard Shortcuts

~ (Tilde) - Toggle console open/closed Escape - Close console (when open) Enter - Execute command or accept autocomplete Tab - Accept autocomplete suggestion Up Arrow - Previous command in history OR navigate autocomplete up Down Arrow - Next command in history OR navigate autocomplete down

🧪 Test Scenario: Basic Setup

Step 1: Create a New Project in TurboWarp

Start with a blank project and load the Developer Console extension.

Step 2: Add Command Registration

Add this to your sprite's "when green flag clicked" script:

when green flag clicked register command [help] with description [Show available commands] register command [test] with description [Test command] register command [echo] with description [Echo back the message]

Step 3: Add Command Handlers

Create these hat blocks for your commands:

when command [help] executed add output [Available commands:] to console add output [- help: Show this message] to console add output [- test: Test command] to console add output [- echo <message>: Echo a message] to console when command [test] executed add output [Test successful!] to console when command [echo] executed set [args] to (command arguments) add output (args) to console

Step 4: Customize Appearance (Optional)

Add styling blocks after command registration:

set console background to [#000000] with opacity [90]% set console text color to [#00ff00] set console font to [Courier New] size [16]px set console border [solid] [2]px color [#00ff00] set console position [bottom] with padding [20]px

Step 5: Test the Console

  1. Click the green flag to start the project
  2. Press ~ to open the console
  3. Type "help" and press Enter
  4. Try typing "t" and watch autocomplete suggestions appear
  5. Use arrow keys to navigate suggestions
  6. Press Tab or Enter to accept a suggestion
  7. Try the "test" and "echo hello world" commands

✅ Acceptance Criteria Checklist

  • Extension loads in TurboWarp without errors
  • Console opens/closes with ~ key
  • Developer can register commands using blocks
  • Commands execute and trigger appropriate handler blocks
  • Autocomplete shows matching commands as user types
  • Styling blocks successfully customize console appearance
  • Console overlays properly on stage without breaking project execution
  • Multiple commands can be registered and executed in sequence
  • Arguments are correctly parsed and passed to command handlers
  • Output messages display in console with proper formatting

🔍 Troubleshooting

Console doesn't open with ~ key

  • Make sure the TurboWarp stage has focus (click on it first)
  • Check browser console for JavaScript errors
  • Verify the extension loaded successfully

Commands not executing

  • Ensure commands are registered before trying to execute them
  • Check that command names match exactly (case-sensitive)
  • Verify hat blocks exist for the commands you're trying to execute

Styling not applying

  • Make sure styling blocks are executed (add them to "when green flag clicked")
  • Try opening and closing the console to see changes
  • Check that color values are valid hex codes

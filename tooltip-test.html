🎯 TurboWarp Tooltips Extension - Test Page

📋 Overview

This test page demonstrates the TurboWarp Tooltips Extension. In a real TurboWarp environment, these tooltips would overlay the stage canvas.

Note: This is a standalone test page. For full functionality within TurboWarp, load the extension via the Extensions menu.

✨ Key Features

📍 Positioning

  • Fixed coordinates
  • Cursor following
  • Custom offsets
  • Viewport-aware

📝 Markdown

  • Headers (H1-H3)
  • Bold, italic, strikethrough
  • Code blocks & inline
  • Lists & links
  • Images & clickable images

🎨 Styling

  • Custom fonts & sizes
  • Colors & opacity
  • Borders & shadows
  • Flexible sizing

⚡ Behavior

  • Fade animations
  • Auto-hide timer
  • Performance optimized
  • Reporter blocks

📖 Usage in TurboWarp

Example 1: Simple Welcome Message

show tooltip [Welcome to my game!] at x: [0] y: [100]

Example 2: Player Stats with Markdown

show tooltip [# Player Stats
HP: 100
Mana: 75
**Level:** 5] following cursor

Example 3: Colored Legendary Item

show tooltip [{color:gold}**LEGENDARY**{/color}

{color:cyan}Sword of Power{/color}

+50 Attack
+25 Defense] at x: [0] y: [0]

Example 4: Custom Styling

set tooltip font to [Georgia]
set tooltip font size to [18]
set tooltip background color to [#8e44ad]
set tooltip border radius to [15]px
show tooltip [*Styled tooltip*] at x: [0] y: [0]

Example 5: Image with Text

set tooltip image max width to [150]px
show tooltip [# Character Info

![Avatar](https://example.com/avatar.png)

**Name:** Hero
**Level:** 25] at x: [0] y: [0]

Example 6: Clickable Image

set tooltip image border radius to [10]px
show tooltip [## Visit Us!

[![Logo](https://example.com/logo.png)](https://example.com)

*Click to visit*] at x: [0] y: [0]

🎓 Markdown Syntax Reference

Text Formatting

  • **bold** → bold
  • *italic* → italic
  • ~~strike~~ → strike
  • `code` → code

Colors

  • {color:red}text{/color}
  • {color:#FF5733}text{/color}
  • {color:rgb(255,100,50)}text{/color}

⚙️ Installation

  1. Open TurboWarp (https://turbowarp.org/)
  2. Click on "Extensions" (bottom left)
  3. Select "Load Extension from URL"
  4. Enter the URL to tooltip.js or load it locally
  5. The "Tooltips" extension will appear in your block palette
⚠️ Important: This extension requires unsandboxed mode to run. TurboWarp will prompt you to confirm when loading the extension.

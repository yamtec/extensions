🎨 Tooltip Image Source Support - Test Guide

This document tests the new universal image source support feature for the TurboWarp Tooltips Extension.

✨ Fixed Bug

Issue: Images could only be loaded from web URLs (HTTP/HTTPS)

Fix: Images can now be loaded from multiple sources including data URLs, blob URLs, Scratch costumes, and relative paths

🎯 Supported Image Sources

1. Web URLs (HTTP/HTTPS) - ✓ Already Working

![Image](https://example.com/image.png) {img:https://example.com/icon.png}

2. Data URLs (Base64) - ✓ NEW

![Embedded](data:image/png;base64,iVBORw0KGgoAAAA...) {img:data:image/png;base64,iVBORw0KGgoAAAA...}

Perfect for embedding small images directly in your project without external dependencies.

3. Blob URLs - ✓ NEW

![Dynamic](blob:http://localhost/abc-123) {img:blob:http://localhost/xyz-456}

Use images from FileReader, Canvas exports, or dynamically generated content.

4. Scratch Costume Names - ✓ NEW

![Sprite Avatar](costume1) {img:my-custom-costume}

Reference any costume from any sprite by name (case-insensitive).

The extension automatically searches all sprites and converts the costume to a data URL.

5. Relative URLs - ✓ NEW

![Local Image](./images/photo.png) {img:../assets/icon.png}

Use relative paths for local development and testing.

🔍 Implementation Details

New Function: processImageSource(source)

This function intelligently handles different image source types:

  • Detects data URLs and blob URLs → passes through unchanged
  • Detects HTTP/HTTPS URLs → passes through unchanged
  • Searches Scratch VM for matching costume names → converts to data URL
  • Fallback: passes through as-is (for relative URLs, etc.)

Modified: All image processing in parseMarkdown() now uses processImageSource()
